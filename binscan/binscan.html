두 폰이 같은 Wi-Fi나 핫스팟에 있어야 합니다. 영상은 폰끼리 직접 전송되고 저장되지 않습니다.

👀 뷰어 폰 손에 드는 폰. 카메라 폰 화면의 4자리 코드를 입력하세요.
사용 순서 / 주의

1. 카메라 폰: "카메라 폰" 선택 → 코드 표시 → 셀카봉에 거치.

2. 뷰어 폰: 코드 입력 후 연결.

3. 뷰어에서 보정: 눈으로 확인한 빈 오버헤드빈 1~2개를 8초간 천천히 쓸어 찍습니다. 이게 그 기체의 정상 기준이 됩니다.

4. 검색 시작 후 실제 검색과 같은 속도로 쓸어갑니다. 기준과 다른 덩어리가 보이면 진동·소리·빨간 테두리.

보조 장비입니다. 알림이 없어도 화면을 직접 확인하세요. 기록은 점수만 남고 영상은 저장되지 않습니다.
